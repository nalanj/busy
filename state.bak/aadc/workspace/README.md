# AADC Workspace Quick Reference

## Available Scripts
- `.scripts/fview.sh` - Quick file viewer
- `.scripts/fsearch.sh` - Search files for text
- `.scripts/git-status.sh` - Git status helper

## Workspace Structure
- `/root/.local/share/aadc/aadc/workspace` - Main workspace directory

## Common Commands
- `ll` - List all files with details
- `la` - List all files (including hidden)
- `ws` - Go to workspace directory
- `scripts` - Go to scripts directory
- `mcd <dir>` - Create directory and cd into it

## Development Tools Available
- bash, python3, node, go, cargo, git
- vim, nano, cat, less, more
- curl, wget, jq
- docker (if available)
